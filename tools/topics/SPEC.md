# 쇼츠 대본 주제 데이터 작성 규격

한국어 유튜브 쇼츠 대본 앱에 들어갈 "바로 찍을 수 있는 대본"을 분야별로 쓴다 (처음 70개씩, 이후 요청마다 추가).
사용자는 목록에서 주제를 고르고, 이미 써진 대본을 조금만 고쳐서 촬영한다. 그러니 그대로 읽어도 되는 완성 문장이어야 한다.

## 출력 파일
`tools/topics/data/<분야id>.json` (기존 배열 끝에 이어 붙인다)

JSON 배열 하나. 원소마다 문자열 배열:
```
["주제 제목", "흐름id", "훅 문장", "구간1 대사", "구간2 대사", ...]
```
- 구간 대사 개수는 흐름마다 정확히 아래 표의 개수. 훅과 마무리(구독·댓글 요청)는 앱이 따로 넣으므로 구간 대사에 넣지 않는다.
- 다 쓰면 반드시 `python3 tools/topics/check.py <분야id>` 를 실행해 오류가 0개가 될 때까지 고친다.

## 흐름id와 구간 (구간 대사 개수)
| 흐름id | 이름 | 구간 순서 |
|---|---|---|
| list3 | TOP 3 순위형 | 3위, 2위, 1위 (3) — 1위가 가장 의외이고 강해야 함 |
| problem | 문제→해결형 | 공감, 원인, 해결, 증명(결과) (4) |
| before | 비포→애프터형 | 비포 상태, 과정1, 과정2, 애프터 결과 (4) |
| story | 썰·스토리형 | 상황, 갈등, 반전, 한 줄 교훈 (4) |
| myth | 통념 깨기형 | 흔한 통념, 실제 근거, 올바른 방법, 한 줄 요약 (4) |
| howto | 따라 하기 | 준비물, 1단계, 2단계, 3단계, 완성 (5) |
| versus | A vs B 비교형 | A 설명, B 설명, 결정적 차이, 조건부 결론 (4) |
| test | 실험·검증형 | 조건, 과정, 뜸("결과는요." 같은 짧은 한마디), 결과, 한 줄 결론 (5) |
| pov | POV 상황극형 | 공감 장면1, 공감 장면2, 과장·반전 (3) — 훅은 "(상황) …" 같은 상황 설정 한 줄 |
| review | 솔직 리뷰형 | 한 줄 평(결론), 장점1, 장점2, 단점, 추천 대상 (5) |
| routine | 루틴·브이로그형 | 장면1, 장면2, 장면3, 소감 (4) |
| news | 이슈 해설형 | 무슨 일, 왜 중요, 내게 미치는 영향, 지금 할 일 (4) |
| quiz | 퀴즈 참여형 | 보기 제시(1번…, 2번…, 3초 드릴게요), 정답, 해설 (3) |
| recap | 요약·압축형 | 설정, 사건, 절정(결말 직전에서 끊기), 한 줄 평 (4) |

## 길이 (공백 제외 글자 수, 훅+구간 대사 합계)
- 20초 분야: 70~105자 / 30초: 120~165자 / 45초: 180~240자 / 60초: 240~320자
- 훅은 10~22자 (3초 안에 읽혀야 함). 구간 한 줄은 한 호흡, 길면 두 문장으로.

## 반드시 지킬 쇼츠 원리
- 훅: 숫자, 질문, 경고, 결과 먼저, 통념 반박, 정보 격차 중 하나로 3초 안에 궁금증을 만든다. 인사·자기소개 금지. 훅과 첫 구간이 같은 말을 반복하지 않는다.
- 한 영상 = 약속 하나. 구체적인 행동, 숫자, 사례, 감각 표현. "꿀팁 알려 드릴게요" 같은 빈말 금지.
- 말투는 존댓말 ~요체 (짧고 구어체). 문장 끝 마침표.
- 사실 확인이 필요한 정확한 수치, 법·제도 세부, 최신 가격·금리·정책 수치, 실제 가게·제품 상호를 지어내지 않는다. 확실하지 않으면 일반적인 표현("보통", "대부분")을 쓴다. 의학·투자 단정 금지.
- 제목은 25자 이내, 검색될 핵심어가 앞쪽에. 70개 주제가 서로 겹치지 않게 세부 주제를 넓게 퍼뜨린다 (초보/실수/돈/시간/계절/상황/비교/숨은 기능/상식 깨기 등).
- 흐름은 분야 추천 흐름 위주로 쓰되 최소 4종류 이상을 고르게 섞는다 (한 흐름이 40%를 넘지 않게).

## 예시 (지식·꿀팁, 30초, problem)
["자취방 곰팡이 없애는 법", "problem", "곰팡이, 락스로 닦으면 또 생겨요.", "닦아도 닦아도 일주일이면 다시 까맣게 올라오죠.", "원인은 곰팡이가 아니라 벽에 갇힌 습기예요.", "과탄산소다를 따뜻한 물에 풀어 뿌리고, 하루 두 번 10분씩 창문을 열어 주세요.", "습기만 잡아도 다시 생기는 속도가 확 느려져요."]
